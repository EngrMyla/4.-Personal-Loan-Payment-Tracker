# Journey to Debt-Free Future (Debt-Free App)

A Python-based terminal app designed to help users track their debts, monitor payment progress, and generate a visual debt summary in SVG format for personal progress tracking.

### Features
- Track debts across multiple banks or lenders
- View a clear debt summary
- Record payment history
- Publish a monthly debt-free journey snapshot

### How to Run
1. Open the project folder.
2. Make sure that Python is installed on your device.
3. Run the following command in PowerShell:
```bash
py debt_free.py
```
4. Navigate and interact with the app.

### Requirements
- Python 3.x
