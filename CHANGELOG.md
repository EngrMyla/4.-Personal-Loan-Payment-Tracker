# Debt-Free App Changelog

### [0.1.0] Nov 13, 2026

#### Added
- Added debt tracking for multiple banks or lenders
- Added debt summary viewing
- Added payment recording and payment validation
- Added ranked debt display in descending order by debt amount
- Added SVG summary generation for monthly debt-free progress
- Added a cleaner, more polished debt journey dashboard
- Added motivational status labels for debt progress
- Added output folder generation for exported SVG files
- Added auto-opening of generated SVG files in VS Code

#### Fixed
- Fixed runtime issue caused by missing SVG status constants in the publish flow
- Fixed payment selection list to show numbered banks clearly
- Fixed payment flow to prevent selecting zero-balance debt records
- Fixed display logic for row limits and overflow entries in SVG summaries
- Fixed layout spacing and formatting for SVG content
- Improved status badge readability by shortening label text
- Improved message clarity for publishing and file output
